# Portal submission copy

ConditionBond is a GenLayer Studio Dev physical-condition escrow dApp. It freezes BEFORE evidence, return criteria, acceptable wear, material damage policy, and a funded GEN bond. The custodian submits AFTER evidence; GenLayer validators compare both images and agree on `UNCHANGED`, `ACCEPTABLE_WEAR`, `MATERIAL_DAMAGE`, or fail closed to `UNDETERMINED`. Settlement is deterministic and `UNDETERMINED` never pays.
